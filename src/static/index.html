Resume Customizer

Resume Customizer is a web application that tailors an existing resume to a job description using Anthropic’s Claude models.

Users upload a LaTeX (.tex) resume or connect Google and pick a Google Doc. The app rewrites wording to match the posting, keeps claims grounded in the source resume, and checks that the customized version does not grow past the original page count.

Optional Google sign-in lets the app copy and edit only files the user picks (and files it creates in a Drive folder named ResumeCustomizer). It does not overwrite the original Google Doc. A shared app password is required to use the tool itself.
